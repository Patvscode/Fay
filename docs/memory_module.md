# Fay Memory Module

This document describes the default cognitive-memory implementation used by `llm/nlp_cognitive_stream.py` and `genagents/modules/memory_stream.py`.

## Memory nodes

- Node types: `observation`, `conversation`, and `reflection`
- Fields:
  - `node_id`: Incrementing integer identifier
  - `node_type`: Node type
  - `content`: Plain-text memory content with `<think>` and `<prestart>` removed
  - `importance`: Integer importance score
  - `datetime`: Creation time in `YYYY/MM/DD HH:MM:SS` format; older nodes may leave this empty
  - `created` / `last_retrieved`: Integer time steps
  - `pointer_id`: IDs of source nodes referenced by a reflection node
- Creation paths:
  - Observations: `remember_observation_thread` / `record_observation`
  - Conversations: `remember_conversation_thread`, using the format `{user}: {question}\n{agent}: {answer}`; the generic `user` role is stored as `Owner`
  - Reflections: Generated by `MemoryStream.reflect`
- Persistence: New memories remain in memory until a scheduled save or shutdown calls `llm/nlp_cognitive_stream.py::save_agent_memory`
- Embeddings: Generated by `memory_stream._add_node`; a mismatched vector dimension is recalculated temporarily during retrieval without immediately writing it to disk

## Retrieval and prompt formatting

- `MemoryStream.retrieve` combines recency, relevance, and importance weights.
- Associated memories are retrieved once with `curr_filter="all"`, then grouped by type.
- Nodes with a `datetime` value are prefixed with `[{datetime}]`; nodes without one omit the timestamp.
- Associated-memory output lists the Observation, Conversation, and Reflection sections directly without an additional heading.

## Configuration and isolation

- `memory.isolate_by_user`: When enabled, memory directories are isolated by username.

## Runtime behavior

- A text request with `no_reply=true` and an `observation` records only the observation and sends no reply.
- An observation without `messages` forces `no_reply=true`.
- In a normal conversation with `no_reply=false`, the question and answer are written to conversation memory. Any supplied observation is also written to observation memory.
- Prompt logging is disabled because `_log_prompt` is a no-op.

## File locations

- Core logic: `llm/nlp_cognitive_stream.py`
- Memory structure: `genagents/modules/memory_stream.py`
- Scheduled saving: `llm/nlp_cognitive_stream.py::save_agent_memory`
- Memory data: `memory/memory_stream/nodes.json`, `embeddings.json`, and `meta.json`
